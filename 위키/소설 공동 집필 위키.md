## 1. 작품 한 줄 정의

| 항목 | 내용 |
| --- | --- |
| 가제 | 수속성 마법사 이강산 |
| 로그라인 | 이강산 헌터의 성장기 |
| 장르 | 현대 판타지 / 길드 / 마법 |
| 주요 소재 | 이강산씨의 성장기 |
| 타깃 독자 | 사람 |
| 분량 목표 | 장기 연재 |
| 연재처 | 네이버 웹소설 |

## 2. 참여자

| 이름 | 담당 | 주 작업 요일 |
| --- | --- | --- |
| 김연우 | 주 스토리 | 월~일 짬시간 |
| 양정후 | 주 스토리 | 월~일 짬시간 |
| 김세훈 | 주 스토리 및 서브 | 월~일 짬시간 |

> 작가 3명(김연우·양정후·김세훈)은 작중 캐릭터로도 같은 이름으로 등장한다. **의도된 셀프 인서트.** (확정)

## 3. 3줄 요약

- **발단:** 주인공이 F급으로 판정됨
- **전개·위기:** 주인공이 마물들과 악마들(마물 악마·성좌 악마 둘 다)을 무찌름
- **절정·결말:** 주인공의 각성 및 흑막과의 전투

## 4. 핵심 갈등 축

| 축 | 한쪽 | 반대쪽 | 이게 왜 안 풀리는가 |
| --- | --- | --- | --- |
| 외적 갈등 | 인류 | 던전 등 | |
| 내적 갈등 | 이강산 | 인주원 | 신념 (원래 품은 신념을 어둠의 카드가 극단적으로 키움) |
| 세계관 갈등 | 지구 | 타우주 | 불신·동맹·전쟁 — 처음엔 지구와 다른 우주들이 싸우다가, 다른 우주끼리 전쟁이 벌어지면서 지구가 일부 우주와 동맹해 같이 싸우는 흐름 (대략 방향) |
