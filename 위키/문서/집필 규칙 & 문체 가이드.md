# 📏 집필 규칙 & 문체 가이드

> 공동 집필이 망하는 이유는 보통 재능이 아니라 **규칙이 없어서**입니다. 시작 전에 여기부터 합의.

## 1. 작업 흐름

1. 쓰기 전 **설정·용어 사전**과 **복선 추적** 확인
2. 화별 집필 관리에 항목 만들고 상태를 `진행 중`으로
3. 초고 작성 → 상태 `완료`
4. 다른 사람이 검토 (최소 1명)
5. **새로 생긴 설정을 DB에 반영** → `설정 반영 완료` 체크

> [!WARNING]
> 5번을 건너뛰면 3개월 뒤에 아무도 설정을 모릅니다.

## 2. 절대 규칙

- 남의 캐릭터를 **죽이거나 큰 결정을 시키지 않는다.** 무조건 담당자와 상의.
- 확정된 설정과 충돌하는 전개는 쓰지 않는다. 바꾸고 싶으면 먼저 논의.
- 남의 원고를 직접 고치지 않는다. 코멘트로 남긴다.
- 갱신 못 할 것 같으면 **미리** 말한다.

## 3. 문체 통일

| 항목 | 규칙 |
| --- | --- |
| 시점 | (미확정·구상 중) 인물별 1인칭. 본편 화는 이강산 시점, 같은 화의 다른 인물 시점은 '-1' 번호로 함께 올림. (예: 10화 = 이강산 시점, 10-1화 = 김연우 시점) — 프롤로그는 이강산 1인칭 |
| 시제 | 과거형 기본 |
| 대사 부호 | `"…"` 대사, `'…'` 속말 |
| 장면 전환 | 빈 줄 + `*` 또는 공백 한 줄 |
| 한 문단 길이 | 3문장 이내 권장 |
| 숫자 표기 | 한글 / 아라비아 → 택 1 |
| 지문 비율 | 대사 : 지문 ≈ ○ : ○ |

## 5. 화의 기본 구조

- [ ] 이 화에서 **뭐가 변했는가**가 한 줄로 설명되는가
- [ ] 끝에 다음 화를 보게 만드는 훅이 있는가
- [ ] 새 설정이 생겼다면 DB에 적었는가
- [ ] 캐릭터 말투가 설정 시트와 맞는가
- [ ] 성장한 캐릭터가 있다면 캐릭터 DB 스탯을 현재 시점으로 갱신했는가

## 6. 분쟁 해결

1. 둘 다 한 줄로 근거를 적는다
2. 그래도 안 되면 **해당 파트 담당자의 의견 우선**
3. 세계관 근간을 건드리는 건 전원 합의
