# 해킹


- 효과: 마력의 흐름(결계·마법·장비·측정기·생명체 안 흐름)이 글자와 선으로 짜인 구조로 보인다. 그 구조를 읽고 → 끼어들고 → 고쳐 쓴다. 단계: ① 읽기(함정·약점·결계 틈·기계 수치) ② 간섭(남의 마법·결계 흐름을 몇 초 끊거나 비틀기) ③ 고쳐 쓰기(장비·아티팩트 성질 변경, 아군 마력 흐름 정리) ④ 각성 = 현실조작(마력 없는 현실의 값까지 다시 씀: 거리·무게·방향·물질 상태).
- 대가: 마력 소모 큼, 과사용 시 두통·코피·시야가 깨진 화면처럼 일그러짐. 각성 후 현실조작은 고쳐 쓸 때마다 자기 심상세계의 줄(기억·감정) 일부가 지워짐.
- 제약: 성좌·초월자처럼 격이 높은 존재의 구조는 읽기조차 어려움. 현실조작은 범위·시간 제한.
- 발동 조건: 집중과 시간 필요(복잡할수록 오래). 대상에 손이 닿아야 하는 단계도 있음.
- **'해킹'은 본문 금지어.**
