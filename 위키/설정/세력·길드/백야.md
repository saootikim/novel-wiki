# 백야


정부 군사 쪽(국가 소속) 길드. 민사하 소속.

- 목적·이념: 길드 간 분쟁 중재 (마석 쟁탈전에 중재하러 개입)

## 23~50화 초안에서 추가 (임시, 23~50화 초안 기준 · 작가 확인 필요)

- 1중대장 민사하. 28~29화 새벽을 정장 쪽으로 오해해 진압 → 30화 김도율 통신으로 해소 → 35화 정보 공유 협정(계약서 없음, 정장 남자와 마주치면 먼저 연락). 46화 공장 정문 양동.
