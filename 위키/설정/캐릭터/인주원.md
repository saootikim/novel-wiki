# 인주원


## 23~50화 초안에서 추가 (임시, 23~50화 초안 기준 · 작가 확인 필요)

- 흑화 단계: 손 차가움(26화) → 입김·서리(28화~) → 두 손 공개(34화: 오른손 흰 서리, 왼손 손바닥 검음) → 손목~팔꿈치(41~43화) → 50화 검은 카드 첫 사용 후 어깨·목덜미까지.
- 왼손이 주변 힘을 빨아들임(그 산 공기, 문지기 안개). 그 바다 물과 물 손이 왼손을 피함. 하얀 카드 빛이 검은색을 한 마디 밀어냄(강산이 손을 잡을 때).
- 43화 '천사'라 자칭하는 목소리를 들음(카드를 준 존재) "그 손을 펴면 다 지킬 수 있어".
- 50화: 검은 카드를 왼손이 삼킴, 반말 "괜찮아. 이제 다 지킬 수 있어", 눈이 그 존재를 닮음. **담당 작가 확인 필수.**
