# 김세훈과 김연우


김세훈 → 김연우 (검술 스승과 제자)

- 시작된 계기: (임시) 연우가 늪에서 세검(아티팩트)을 얻은 뒤 세훈에게 검술 기초를 배움(14화 이후 예정). 세훈은 조건우의 제자 → 같은 스승 줄기, 다른 검(세훈 = 베기, 연우 = 찌르기).
